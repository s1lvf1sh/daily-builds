Instant-runoff rounds

The rules in one line each

  • Plurality: most first choices.
  • Instant runoff: drop the option with fewest first choices (all that tie), pass those votes down, repeat until one has over half. Voters whose listed options are all gone stop counting.
  • Borda: each ballot gives an option 1 point per option it beats, half a point per tie.
  • Copeland: 1 point per head-to-head win, half per tie.
  • Minimax: the option whose worst head-to-head margin is least bad.
  • Schulze: the option with the strongest chain of head-to-head wins over every rival. Ties are reported as ties, never broken by chance.
