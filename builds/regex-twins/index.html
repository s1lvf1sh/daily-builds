Regex Twins

Type two regular expressions. It does not test them on samples: it builds the exact machine for each and tells you whether they match the same strings. When they don't, it gives you the shortest string that tells them apart.

Try:

Try a string on both

Supported: literals, . [a-z] [^…] \d \w \s \D \W \S | ( ) (?:) * + ? {n} {n,} {n,m}. The whole string must match, over printable ASCII (space to ~). Not supported because they are not regular: backreferences, lookaround, anchors, word boundaries.
