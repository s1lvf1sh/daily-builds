# Dice Duel: Value & Future

## Value

For a tabletop player or game designer who asks "is advantage better than +5?" it answers exactly and immediately, with the whole distribution and a target-number table. That is real but narrow, and tools that do the same sort of thing already exist, so I would not expect many people to prefer this one.

## Limitations

- Only a small dice language: no rerolls, exploding dice, success counting, or multi-step rolls.
- Two independent expressions only; no three-way or tournament comparison.
- No one has used it, so the first-ten-seconds experience is judged from screenshots.
- The chart does not show the cumulative curve.
- Accessibility is only lightly considered.

## Where it could go

| Direction | What it adds | Effort (S/M/L) |
|---|---|---|
| Success counting and rerolls | Covers pool systems | M |
| Exploding dice (truncated depth, with a stated error bound) | A common request | M |
| Rounds-to-kill: damage per round against hit points | Answers the real question | M |
| Cumulative curve and "beats by at least N" | More detail from the same engine | S |
| Save named matchups in the browser | Return visits | S |

## Recommended next move

Ask someone who plays tabletop games what they would type first, and build that, rather than guess.
