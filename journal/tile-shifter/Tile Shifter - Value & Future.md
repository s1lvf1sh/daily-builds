# Tile Shifter: Value & Future

## Value
A toy first: shaping a tile and watching the plane re-tile is fun to try for a minute. Beyond that, the downloaded outline can be cut (cardboard, wood, laser) for a handmade tessellation, and a teacher can use it to show that a bump on one side must be a dent on the other. Honest Use is low; this is a plaything with a craft side.

## Limitations
- Translation tilings only: no rotation, no glide, no flip-and-rotate Escher tiles.
- No drawing on the tile, so no creature faces; shapes read as blobs unless you imagine.
- Tiles are always three-coloured by lattice position, not by design.
- Not tested on touch devices or printed.

## Where it could go
| Direction | What it adds | Effort (S/M/L) |
|---|---|---|
| Rotation and glide edge types | The classic Escher families | M |
| Paint or stamp eyes on the tile | A creature, not a blob | M |
| Print layout with a cutting border | Real craft use | S |
| Gallery of shared links | Makes sharing worthwhile | L |

## Recommended next move
Ask someone to try it before adding anything, then add drawing on the tile if people enjoy the dragging.
